# Architecture

This directory will document Environode's architecture decisions, diagrams, data flow, and implementation phases.

## Initial Shape

- `apps/web`: React/Vite dashboard.
- `services/api`: Node.js/Express REST API.
- `firmware/stm32-h753`: STM32CubeIDE project for NUCLEO-H753ZI.
- `tools/device-simulator`: Node.js telemetry simulator.
- `docs`: architecture, API, firmware, security, and demo documentation.
