# Demonstração local

A tela de entrada é a mesma para todos os clientes e não mostra nomes ou credenciais. Estas contas são fictícias e servem somente para testar o projeto no computador local:

| Cliente fictício | E-mail | Senha |
| --- | --- | --- |
| NovaLab Electronics | `ana@novalab.example` | `demo123` |
| Circuito Verde Labs | `bruno@circuitoverde.example` | `demo123` |

Entre com uma conta, confira as centrais e alertas, saia e entre com a outra. Os equipamentos e sensores exibidos mudam conforme a conta autenticada. A NovaLab tem 10 centrais com quatro sensores cada; a Circuito Verde tem uma central com dois sensores. Nenhuma leitura é transmitida em tempo real nesta fase.
